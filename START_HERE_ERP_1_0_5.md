# Samara Care ERP 1.0.5

## Intelligent Report corrections
- A4 portrait print layout.
- Print/Save PDF filename uses: Patient Name - Report as on date_time.
- Blank vital records are ignored and never classified as critical.
- In the absence of abnormal findings, the report states that the patient is clinically stable on available records.
- Active prescriptions and active care-plan instructions are described in the human clinical narrative.
- No SQL or Edge Function update is required.

Deploy all files to GitHub Pages and refresh with Ctrl+Shift+R.
