# Samara Care ERP V9.1 – Intelligent Reports

## Included
- Patient-wise consolidated report
- Day-wise operational report
- Intelligent narrative summary
- Vitals, MAR, care, meals, physiotherapy, incidents, billing, recovery and documents
- Print / Save PDF

## Deployment
1. Replace repository files with this package.
2. Commit and wait for GitHub Pages.
3. Open in Incognito first.
4. Press Ctrl+Shift+R.
5. Open MANAGER → Intelligent Reports.

No SQL update is required.
