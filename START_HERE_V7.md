# Start Here — Samara Care ERP V7

1. In Supabase SQL Editor, run `supabase/sql/15_V6_5_MASTER_INSTALL_OR_REPAIR.sql` once.
2. In Supabase Edge Functions, replace and deploy `admin-users` using `supabase/functions/admin-users/index.ts`.
3. Upload this package to the GitHub repository `Samara_AL_ERP_V7`.
4. Enable GitHub Pages: main branch, root folder.
5. Open the live URL and hard-refresh once.
6. Test Admin, Manager, Nurse, Caregiver, Accounts and Kitchen logins.
7. Test employee photo/document upload and patient document upload.
