# Samara Care v3.1 Upgrade

1. Open Supabase → SQL Editor.
2. Open `supabase/sql/05_safe_admission_risk_tasks.sql` from this package.
3. Copy all its contents, paste into SQL Editor and click **Run**.
4. Replace the files in your GitHub repository with this package.
5. Wait for GitHub Pages deployment, then refresh the app.

Existing employees and patients are retained.
