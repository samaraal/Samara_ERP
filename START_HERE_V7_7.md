# Samara Care ERP V7.7 – Unified Patient Master

## What changed
- Patient Master is now the central file for documents, medicines/MAR, nursing care, vitals, physiotherapy, diet, billing, recovery and incidents.
- All patient dropdowns show Patient ID and room/bed status.
- Rooms & Beds shows active Patient Master records awaiting allocation.
- Possible duplicate patients are highlighted.
- No SQL update is required.

## Deployment
1. Replace the GitHub repository files with this package.
2. Commit and wait for GitHub Pages deployment.
3. Press Ctrl + Shift + R.
4. Open ADMISSION → Patients and test a Patient File.
