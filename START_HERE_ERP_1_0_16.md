# Samara Care ERP 1.0.16 – Clinical Dashboard & Vital Signs

## Included
- Role-based Clinical Dashboard for Nurses and Caregivers
- Medicines due and overdue worklist
- Vitals, care and physiotherapy pending counts
- Open incident and latest shift-handover panels
- Expanded Vital Signs entry with respiration, weight and pain score
- Automatic Normal / Warning / Critical classification
- Patient-specific latest values and recent trend table

No SQL update is required when the existing vital_signs table already contains respiration, weight and pain_score columns.
