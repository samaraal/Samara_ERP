SAMARA CARE ERP v2.10.31 — DIRECTOR'S OFFICE QUICK TASKS

NEW
---
A separate SHORT FORM for simple everyday Director's Office tasks.

Examples:
- Visit someone
- Buy / Purchase something
- Attend a function
- Trip / Travel
- General task

NEW BUTTON
----------
Director's Office -> + Quick Task

The existing + New Item remains unchanged for detailed:
Appointment / Call / Follow-up / Visitor / Correspondence / Reminder.

QUICK TASK FORM — ONLY ESSENTIALS
---------------------------------
1. Task type
   - Visit
   - Buy / Purchase
   - Attend Function
   - Trip / Travel
   - General Task

2. What to do?
3. Person / Place (optional)
4. Date & Time
5. Priority
6. Short Note (optional)

Status is automatically Pending for a new task.
When editing an existing task, Status is available.

The Quick Task form does NOT ask for:
- Mobile
- Organisation
- Follow-up due date
- Director instruction
- Needs Director Attention

DASHBOARD
---------
A new Tasks box shows pending/open quick tasks.
Task records can be filtered separately from appointments, calls, etc.

INSTALL
-------
1. Run in Supabase SQL Editor:
   110_director_office_quick_tasks.sql

2. Replace ERP files:
   app.js
   index.html
   service-worker.js

3. Refresh once.

NO EDGE FUNCTION CHANGE.
