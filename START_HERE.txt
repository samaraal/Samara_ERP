SAMARA CARE ERP v2.10.26 — APPROVED TODAY SUMMARY

CHANGE
------
The old cumulative "Approved" / "Approved Value" cards have been replaced with
operational daily information:

1. Today's Entries
   - Number of charge requests raised today.

2. Pending Approval
   - Current pending charge requests.

3. Approved Today
   - Number of charges actually approved / partially approved today.

4. Approved Value Today
   - Total actual amount approved today.

DATE LOGIC
----------
"Approved Today" uses the actual approval decision timestamp (decision_at).
For older legacy rows where decision_at is blank, charge_date is used only as a
fallback.

NAVIGATION
----------
All four cards remain clickable.

- Today's Entries -> today's charge requests
- Pending Approval -> pending only
- Approved Today -> approvals made today
- Approved Value Today -> same approval-today detail list

The historical approved total is no longer shown on the dashboard. Historical
records remain available in the full Bills & Charges Register.

INSTALL
-------
Replace only:
- app.js
- index.html
- service-worker.js

Then Ctrl+F5 once.

NO SQL REQUIRED.
NO EDGE FUNCTION CHANGES.
