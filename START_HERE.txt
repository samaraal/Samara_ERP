SAMARA CARE ERP v2.10.28 — MANAGER PERSONAL TO-DO & FOLLOW-UP

PURPOSE
-------
A private personal organiser for each Manager.

PRIVACY
-------
- Each Manager sees ONLY items created under their own login.
- Other Managers cannot see them.
- Admin cannot see them through the ERP or normal authenticated database access.
- STD, HR, Accounts, Nurse, Caregiver, Kitchen cannot access them.
- Privacy is enforced by Supabase Row Level Security (RLS), not merely hidden in the UI.

MANAGER DASHBOARD
-----------------
New private navigation box:
- Due Today
- Overdue
- Follow-ups Pending
- Completed Today

MY TO-DO & FOLLOW-UP
--------------------
Manager can:
- Add task / follow-up
- Category: General, Patient/Relative, Staff, Vendor, Maintenance, Billing, Admission
- Priority: Low, Normal, High, Urgent
- Due date & time
- Follow-up date & time
- Notes
- Status: Pending, In Progress, Waiting, Completed
- Complete
- Remind Tomorrow
- Edit
- Delete
- Filter Open / Today / Overdue / Follow-up / Completed / All

INSTALL ORDER
-------------
1. Supabase SQL Editor:
   Run 109_manager_personal_todo.sql

2. ERP hosting:
   Replace app.js
   Replace index.html
   Replace service-worker.js

3. Ctrl+F5 once.

NO EDGE FUNCTION CHANGE REQUIRED FOR THIS FEATURE.

IMPORTANT
---------
The supplied admin-users Edge Function is retained in the ZIP because it belongs
to v2.10.27 My Profile. If you already deployed v2.10.27, you do not need to
redeploy it for this v2.10.28 Manager To-Do feature.
