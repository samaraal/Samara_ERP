SAMARA CARE ERP v2.10.29 — MOBILE FORM CLEAN SCREEN

FIX
---
On mobile, the large "Module — Director's Office" selector remained visible
while an entry form/modal was open. It used valuable vertical screen space and
made the form look cramped.

NOW
---
Whenever ANY modal / entry form is open on mobile:
- The Module selector is temporarily hidden.
- The bottom mobile navigation is already hidden as before.
- The form gets the full usable screen height.
- When the form is closed, the Module selector returns automatically.

This especially cleans up:
Director's Office -> New Item / Edit Item

INSTALL
-------
Replace only:
- app.js
- index.html
- service-worker.js

Then Ctrl+F5 once.

NO SQL.
NO EDGE FUNCTION CHANGES.
