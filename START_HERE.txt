SAMARA CARE ERP v2.10.22 — STD ENQUIRY DESK

PURPOSE
-------
STD should attend enquiries, not every WhatsApp communication in Samara ERP.

WHATSAPP ENQUIRY DESK
---------------------
STD now sees only enquiry-type WhatsApp conversations.
Hidden from STD:
- HR applicant / employee WhatsApp
- Patient / family operational WhatsApp
- Emergency messages
- Payment / receipt messages
- Daily patient reports
- Discharge messages
- Family Portal operational messages

STD WhatsApp filters:
- Subject
- Name / mobile / message search
- From date
- To date
- Unread only

Automatic subject groups:
- Admission / Care
- Callback
- Location
- Pricing / Charges
- Services
- General Enquiry

CALL ENQUIRIES
--------------
Calls are entered manually by STD.

Director's Office > Call Enquiries:
- Caller Name
- Mobile
- Call Subject / Enquiry
- Organisation
- Call Date / Time
- Follow-up / Due Date
- Details
- Priority
- Status
- Director Note / Instruction

The Director Follow-up Queue can now be filtered by:
- Subject / name / mobile / notes
- From date
- To date
- Type / status

The Call Enquiries dashboard card can be clicked to immediately enter a new call.

INSTALL
-------
1. Supabase SQL Editor:
   Run 107_std_enquiry_whatsapp_rls.sql ONCE.

2. ERP hosting:
   Replace:
   - app.js
   - index.html
   - service-worker.js

3. Ctrl+F5 once.

Do NOT rerun SQL 104/105/106.
Do NOT change WhatsApp Edge Functions.

IMPORTANT
---------
STD remains a transferable ROLE. Nothing is hard-coded to Akshai.
