SAMARA CARE ERP v2.10.30 — CLEAN FULL-SCREEN MOBILE FORMS

WHAT WAS WRONG
--------------
On iPhone/mobile, a form could still sit underneath:
- Samara header / page title
- Global Search
- Module selector
- Enable Alert Sound bar
- Bottom navigation

This reduced the usable form area and could hide the top portion of long forms.

FIX — APPLIES TO ALL REAL MODALS / ENTRY FORMS
-----------------------------------------------
While any form/modal is open on mobile:

1. Samara page header and global search are hidden.
2. Module selector is hidden.
3. Enable Alert Sound bar is hidden.
4. Bottom mobile navigation is hidden.
5. Clinical alert popup is temporarily hidden (not resolved/cleared).
6. The form itself becomes a true full-screen layer.
7. Long forms scroll independently from top to bottom.
8. Form title / Close button remain sticky at the top while scrolling.
9. Closing the form automatically restores the normal ERP screen.

This is a GLOBAL mobile correction, so it applies to Director's Office and
all other modal/entry forms that use the standard Samara modal structure.

INSTALL
-------
Replace only:
- app.js
- index.html
- service-worker.js

Then refresh once (Ctrl+F5 on desktop; close/reopen or reload PWA on mobile).

NO SQL REQUIRED.
NO EDGE FUNCTION CHANGES.
