SAMARA CARE – UPDATE POPUP LOOP FIX

Cause:
app.js still reported APP_VERSION 2.9.64 while service-worker.js reported 2.9.65.
Therefore the ERP continuously believed 2.9.65 was a newer version and showed the update popup after every refresh.

Fix:
Replace ONLY app.js with the included file.
No SQL or other file change is required.

After deployment:
1. Fully close the Samara Care app/browser tab.
2. Reopen it once.
3. If the update prompt appears once more, tap OK once. It should not repeat after that.
