SAMARA CARE ERP v2.10.37 — DIRECTOR OFFICE RESCHEDULE + CANCEL

WHAT IS NEW
-----------
Every open Director's Office item now has:
- Reschedule
- Complete
- Cancel

RESCHEDULE
----------
Opens a compact form:
- New Date (required)
- Time (optional)
- Reason / Note (optional)

The item remains Pending and its previous/new schedule is retained in
reschedule_history. Applies to Tasks, Appointments, Calls, Follow-ups,
Visitors, Correspondence and Reminders.

CANCEL
------
Cancellation does NOT delete the item. Status becomes Cancelled and the
optional reason + cancellation time are retained. A Cancelled filter has
been added beside Completed.

INSTALL ORDER
-------------
1. Supabase SQL Editor: run 112_director_office_reschedule_cancel.sql once.
2. Website / ERP hosting: replace ONLY these files:
   - app.js
   - index.html
   - service-worker.js
3. Reload Samara Care. If an old version remains, use App Help / Repair App.

NO EDGE FUNCTION CHANGE
-----------------------
The working OpenRouter/Gemini director-office-voice function is untouched.
Do not replace or redeploy the voice Edge Function for this update.
