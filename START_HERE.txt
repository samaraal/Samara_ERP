SAMARA CARE — WhatsApp SEND + APPROVED TEMPLATE FIX

The current code had two independent sending problems.

1. DIRECT MESSAGE
The ERP was calling whatsapp-send with message_type='image', but the deployed function handled only text/template. Direct replies can therefore fail even while the 24-hour window is open.
This package changes the ERP direct reply to a true text message and makes whatsapp-send support text, image and template correctly.

2. GENERAL FOLLOW-UP TEMPLATE
The approved samara_general_followup shown in Meta contains ONE body variable:
{{1}} = Customer name
The older manual Inbox code could still pass a second 'Regarding' variable. The ERP and Edge Function now both enforce the correct one-variable payload.

3. META DELIVERY STATE
The function now returns Meta's initial message_status. The webhook records a held state when Meta holds a newly-approved template for assessment. If that happens after an incoming enquiry, it sends a direct acknowledgement immediately because the 24-hour reply window is already open.

DEPLOY THESE FILES

ERP:
- Replace app.js only

Supabase Edge Functions:
- whatsapp-send/index.ts
- whatsapp-webhook/index.ts

Do NOT replace index.html or service-worker.js.

TEST IN THIS ORDER
1. With 'Reply window open', type 'Test reply from Samara' in Direct message and press Send.
2. If received, press General Follow-up > Send template.
3. Then send 'Hi' from the phone and confirm the automatic reply.
