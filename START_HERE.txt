SAMARA CARE ERP v2.10.27 — MY PROFILE FOR ALL STAFF

NEW
---
Every logged-in employee now has:
  MY ACCOUNT -> My Profile

The user card at the bottom of the left sidebar is also clickable and opens
My Profile directly.

MY PROFILE
----------
Official HR-controlled details (read-only):
- Employee ID
- Full Name
- Department
- Designation
- ERP Role / Access
- Date of Joining

Employee-editable contact details:
- Mobile
- Email
- Address
- Emergency / Guardian Contact

LOGIN & SECURITY
----------------
Every active employee can:
- Change Login ID / Username
- Change Password

SECURITY RULES
--------------
1. Login ID change requires CURRENT PASSWORD.
2. Login ID is checked for uniqueness.
3. Allowed Login ID characters:
   letters, numbers, dot, underscore, hyphen
4. Password change requires CURRENT PASSWORD.
5. New password minimum: 8 characters.
6. New password must differ from the current password.
7. Changing Login ID does NOT change Employee ID, designation, department or role.
8. Staff cannot edit their own employment status or ERP access.
9. Changes are logged in password_security_events.

TRANSFERABLE ROLES
------------------
This works automatically for Admin, Manager, Nurse, Caregiver, Accounts,
Kitchen and STD, including future employees assigned to those roles.
