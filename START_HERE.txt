WHAT IS FIXED IN v2.10.11
• On iPhone/Android, the Patient File now opens ABOVE the sticky Samara header and Module bar.
• The top of the Patient File can no longer be hidden behind the app header.
• “Back to Patients”, patient identity/header, and the first tab row remain accessible.
• The patient tab row is horizontally scrollable and stays available while viewing the file.
• Internal scroll targets use a safe top margin so sections are not hidden below sticky controls.
• Bottom safe-area spacing is preserved for iPhone Home Screen/PWA mode.

DEPLOYMENT
Upload/replace the four files above in the same website root used for the current ERP.
The PWA version was increased from 2.10.08 to 2.10.11, so each device can detect the new release independently.

- Mobile Patient File now takes over the full screen while open; the underlying sticky Header, Module bar, bottom navigation and Alert Sound control are hidden until the file is closed. This avoids iPhone stacking overlap that hid the first rows.
- Identity & Contacts now uses a clean three-part label : value grid (for example, Resident ID  :  MOG-...) with separate Address, District / Taluk and PIN rows for easier reading.
- No SQL or Supabase database change is required.

ADDITIONAL FIX IN v2.10.11
