SAMARA CARE ERP v2.10.25 — CHARGE APPROVAL + NAVIGATION + APPROVED VALUE FIX

FIXES
-----
1. APPROVED VALUE
The previous dashboard calculation used:
  final_amount OR requested_amount

That could incorrectly count requested amounts from old/legacy rows when no
actual approved amount existed.

Now Approved Value uses ONLY:
  approved_amount
or, for older genuinely approved records:
  final_amount

It never falls back to requested_amount.

Therefore the box represents the actual amount approved / posted.

2. APPROVAL BUTTON VISIBILITY
For Accounts login, Approve / Partial / Reject are moved near the LEFT side of
the register, immediately after Decision.

Accounts no longer needs to scroll far right across the long table to find the
Action column.

The financial approval rule itself remains unchanged:
  Accounts only.

3. DASHBOARD BOXES ARE NAVIGATION BOXES
All four summary boxes are clickable:

- Today's Entries
  -> shows today's charge requests

- Pending Approval
  -> shows Pending requests only

- Approved
  -> shows Approved + Partially Approved requests

- Approved Value
  -> opens the same approved-detail view

Clicking a box scrolls directly to the Bill & Charge Requests register.

A "Show All" button clears the quick view.

INSTALL
-------
Replace only:
- app.js
- index.html
- service-worker.js

Then Ctrl+F5 once.

NO SQL REQUIRED.
NO EDGE FUNCTION CHANGES.
NO BILLING DATABASE LOGIC CHANGES.
