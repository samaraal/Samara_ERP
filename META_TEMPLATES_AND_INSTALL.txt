============================================================

============================================================

ERP WORKFLOW
============================================================
WhatsApp Inbox > select family conversation > red "Emergency" button.

Emergency Hospital Transfer captures:
- Resident name
- Hospital name
- Emergency/transfer time
- Contact attempts / remarks
- Preview

Urgent Contact Required captures:
- Resident name
- Time
- Contact attempts / remarks
- Preview

Every successful emergency message is saved in the same WhatsApp conversation with:
- EMERGENCY label
- URGENT sender badge
- sender name
- Meta provider message ID
- Sent / Delivered / Read / Failed updates through the existing webhook

INSTALL
1. Replace app.js.
2. Ctrl + Shift + R.
3. Create and get both templates ACTIVE in Meta.
4. No SQL required.
5. No Edge Function change required if your current whatsapp-send already sends IMAGE headers.

IMPORTANT
The ERP emergency WhatsApp is an additional documented communication channel.
Clinical escalation, ambulance/hospital transfer and telephone attempts must continue
without waiting for WhatsApp delivery/read.
