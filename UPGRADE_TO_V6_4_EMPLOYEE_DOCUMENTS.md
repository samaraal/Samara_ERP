# Samara Care ERP V6.4 – Employee Documents Access

## What changed

- Added a clearly visible **Documents** button for every employee.
- Renamed **View / Edit** to **Personnel File**.
- Employee documents and certificates remain available inside the personnel file.
- The Documents button opens the same secure employee record containing upload, mobile camera, webcam capture and uploaded-document register.
- Updated the PWA cache version so browsers load the new interface.

## Upgrade

Replace the current GitHub application files with this package and commit the changes. No Supabase SQL update is required. After GitHub Pages publishes, refresh with Ctrl + Shift + R.
