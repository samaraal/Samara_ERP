SAMARA CARE ERP v2.11.57 - ALIGNED HANDOVER PLAN
=================================================

Purpose
-------
The Next 24 Hours / Handover Plan is now displayed in aligned columns:

  Label                : Details

All colons remain on one straight vertical line. Long descriptions wrap only
inside the Details column, without moving the label or colon.

The same alignment is applied to:
- The report shown on screen
- Print / Save PDF
- Automatically generated and WhatsApp PDF

Deployment
----------
1. Replace these ERP website files:

   app.js
   styles.css
   config.js
   index.html
   service-worker.js

2. Deploy:

   supabase/functions/daily-patient-report/index.ts

   Command:
   supabase functions deploy daily-patient-report

3. Select Update Now, or use App Help / Repair.
4. Confirm ERP version 2.11.57.
5. Generate a fresh report. New PDF filenames end with aligned_plan_v7.pdf;
   previously generated PDFs will remain unchanged.

No SQL is required for this alignment update.
