# Samara Care ERP V6 Trial Upgrade

1. Supabase > SQL Editor > New query.
2. Run `supabase/sql/12_v6_patient_master_enquiries.sql` completely.
3. Replace the GitHub repository files with this package.
4. Commit and wait for GitHub Pages deployment.
5. Refresh with Ctrl + Shift + R.

## New in V6 Trial
- Admission routes: Hospital Discharge, Direct Admission, Doctor Referral, Hospital Transfer.
- Patient categories and pre-admission enquiries.
- Mandatory patient photograph and identity proof.
- Upload or camera capture for discharge summary, prescription, lab, scan and test reports.
- Private patient-document storage.
- Patient Master file containing identity, contacts, documents, prescription, care plan and physiotherapy.
- Compatibility columns for the Employee Personnel File, including blood group.
