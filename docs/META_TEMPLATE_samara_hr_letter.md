# WhatsApp template: samara_hr_letter (ERP 2.20.9)

Submitted automatically by the ERP (HR → Personnel File → Probation, Exit & HR Letters → "Set up WhatsApp template"),
or by hand in Meta Business Manager with exactly these details:

- Name: `samara_hr_letter` · Category: **Utility** · Language: **English (en)**
- Header: **Document** (sample: any PDF letter)
- Body:
  ```
  Dear {{1}},

  Please find attached your {{2}} from Samara Health Care LLP (Ref: {{3}}).

  For any query, please contact the Samara HR office.
  ```
  Samples: {{1}} Saranya · {{2}} Confirmation Letter · {{3}} SAM/HR/2026-27/001
- Footer: `Samara Assisted Living`

Until Meta approves it, letters are sent as a direct WhatsApp document, which works only if the employee messaged
Samara in the last 24 hours; otherwise the letter shows "Failed" with a Resend button (and View PDF to share by hand).
