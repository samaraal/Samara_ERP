# Samara Care ERP V9.3 – V3 Style & Compact Readability

## What changed
- V3-style split-screen login restored.
- Larger readable text throughout the app.
- Reduced excessive row height and vertical spacing.
- Denser tables, forms, cards and reports while preserving touch-friendly controls.
- No database or Edge Function changes.

## Deployment
1. Replace the GitHub repository files with this package.
2. Commit and wait for GitHub Pages.
3. Open once in Incognito, then use Ctrl + Shift + R in the regular browser.
