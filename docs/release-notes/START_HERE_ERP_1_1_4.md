# Samara Care ERP 1.1.4 – Compact Medication Time Picker

## Changes
- Replaced the long 24-hour expanded list with a compact popup.
- Added OK, Reset and Cancel buttons.
- Selected times appear as removable chips.
- The popup closes after OK or Cancel.
- Applied to New Admission and Existing Patient Edit.
- Existing OD/BD/TDS/QID automatic time suggestions remain unchanged.

## Deployment
Upload all files to the existing GitHub repository, replacing the previous files. No Supabase SQL is required.

After deployment, close and reopen the installed ERP and accept the app update when prompted. Confirm version 1.1.4.
