# Samara Care ERP V7.8

## Patient Profile, Edit and Clinical ID Card

1. Replace the existing GitHub application files with this package.
2. Commit the changes and wait for GitHub Pages deployment.
3. Refresh using Ctrl + Shift + R.
4. Open ADMISSION > Patients.
5. Click a patient name to open the complete Patient File.
6. Use Edit to correct duplicate or wrongly entered details.
7. Print the redesigned Patient Identity & Emergency Card.

No Supabase SQL update is required.
