# Samara Care ERP V6.3 – Camera and Webcam Capture

No Supabase SQL change is required.

## New controls
For Employee Photo, ID Proof, Qualification Certificate, Experience Certificate and Other Certificates, the form now shows:

1. Upload File
2. Mobile Camera
3. Webcam

The Webcam option opens a live camera preview. Select **Capture Photo**, review it, and select **Use This Photo**.

## Deployment
Replace the current GitHub application files with this package, commit the changes, wait for GitHub Pages deployment, and refresh with Ctrl + Shift + R.

Camera access requires HTTPS and browser permission. GitHub Pages provides HTTPS.
