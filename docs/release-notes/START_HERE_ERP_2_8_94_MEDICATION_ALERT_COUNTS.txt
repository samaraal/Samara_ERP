SAMARA CARE ERP v2.8.94 — MEDICATION ALERT COUNT LOGIC ONLY

NO SQL UPDATE REQUIRED.

This update changes only the Nursing Dashboard medication alert/count logic.

Corrections:
1. Nursing Dashboard now uses the same prescription eligibility as Medication Administration:
   - active patient only
   - active medication order only
   - excludes completed / discontinued / stopped / inactive orders
   - excludes orders whose end_date has passed
   - defensive exact-duplicate filter remains
2. "Overdue" is now cumulative. A Critical dose is also counted as overdue.
3. "Critical" uses the configured medication critical threshold (default 60 min).
4. "Escalated" counts actual medication alerts generated by the Clinical Alert Engine;
   simply crossing 30 minutes no longer falsely labels the item as already escalated.
5. Worklist shows "ESCALATION DUE" from the escalation threshold until the critical threshold.
6. No patient, MAR, medication, billing, HR, admission, room, discharge, or other data is changed.

- app.js
- index.html
- service-worker.js

Do not replace styles.css or any folders.
