# Samara Care ERP 1.0.4 – Patient Edit Photo & Documents

This update adds patient photo and medical-document management directly inside **Edit Patient Information**.

## Included
- Existing patient photo preview
- Upload File, Mobile Camera and Webcam for Patient Photo
- Identity Proof
- Current Prescription
- Discharge / Transfer Summary
- Lab / Scan / Test Reports
- Other Medical Documents
- Existing document list with Open and Delete actions
- Photo path is saved back to the patient record

## Deployment
Replace the GitHub repository files, commit, wait for GitHub Pages deployment and refresh with **Ctrl + Shift + R**.

No SQL or Edge Function change is required.
