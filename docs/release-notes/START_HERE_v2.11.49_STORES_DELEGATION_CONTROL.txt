=====================================================

   It is additive and retains the existing assignment and Stores data.

3. ERP → App Help / Repair → Repair App once.

CONTROL
- Only Admin/Director can assign Stores responsibility temporarily to STD.
- Nurse Manager cannot create, modify or cancel the assignment.
- The unused generic Manager role has no assignment authority.
- Admin/Director can use Modify Assignment to change From, Until or Reason.
- Admin/Director can use Cancel Delegation to return responsibility immediately to Nurse Manager.
- Modification and cancellation details are retained in the database change history.
