# Samara Care ERP V9.2 – Human Intelligent Reports

1. Replace the current GitHub files with this package.
2. No SQL update is required.
3. Refresh with Ctrl + Shift + R.
4. Open MANAGER → Intelligent Reports.
5. Generate Patient-wise or Day-wise report and use Print / Save PDF.

The reports are generated from recorded Supabase data. Recommendations are decision-support statements and do not replace a treating doctor’s assessment.
