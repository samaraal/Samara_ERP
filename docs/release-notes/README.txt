Samara Care ERP v2.11.33 — Explicit Enable / Disable Mobile Notification Controls

Replace ONLY:
- app.js
- config.js
- index.html
- service-worker.js

Clinical Alerts now has TWO separate controls, so the status/action is unmistakable:

When notifications are ENABLED:
- GREEN: ✓ Mobile Notifications Enabled
- RED: Disable Mobile Notifications

When notifications are DISABLED:
- GREEN: Enable Mobile Notifications
- RED: ✕ Mobile Notifications Disabled

The top-right bell navigation to Escalated Clinical Alerts is retained.

No medication, vitals, nursing-care, escalation timing, billing, HR, or other workflow changed.
