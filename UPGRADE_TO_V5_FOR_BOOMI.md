# Samara Care ERP V5 — Simple Upgrade

## 1. Supabase
Open **Supabase → SQL Editor → New query**.

Copy the complete contents of:

`supabase/sql/06_v5_unified_modules.sql`

Paste it and click **Run**.

Do not delete the earlier tables or users.

## 2. GitHub
Create/use the repository **Samara_AL_V5**.

Delete the old files in that repository and upload all files and folders from this package. Commit the changes.

## 3. GitHub Pages
In **Settings → Pages**, choose **Deploy from a branch**, `main`, `/(root)`.

The app URL will be:

`https://rajaiahboomi-crypto.github.io/Samara_AL_V5/`

## 4. Refresh
Wait 2–3 minutes, then open the URL and press **Ctrl + Shift + R** once. On iPhone, open it first in Safari and then use **Share → Add to Home Screen**.
