# Samara Care ERP V8.1 — Rooms & Beds Master

1. In Supabase SQL Editor, run `supabase/sql/17_v8_1_rooms_beds_master.sql`.
2. Upload all files in this package to the same GitHub Pages repository root.
3. Wait for deployment, then press **Ctrl + Shift + R**.
4. Open **OPERATIONS → Rooms & Beds**.

Admin and Manager can add/edit rooms, assign or transfer patients, reserve beds, mark maintenance, set room type and daily rate. Other authorised roles have view access.
