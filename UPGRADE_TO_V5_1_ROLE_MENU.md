# Samara Care ERP V5.1 – Role-Based Sectional Menu

This upgrade reorganises the long menu into sections:

- Overview
- Admin
- Admission
- Manager
- Nursing
- Operations
- Food & Diet
- Accounts / Billing

Admin and Manager can access all modules. Nurse, Caregiver, Accounts and Kitchen users see only modules relevant to their roles.

The desktop sidebar has its own scrollbar. On mobile, modules appear in one grouped drop-down selector.

## Upload
Replace the existing GitHub files with this package. No new Supabase SQL is required for this menu-only upgrade.
