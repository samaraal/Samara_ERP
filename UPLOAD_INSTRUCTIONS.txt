SAMARA CARE ERP v2.8.31 — ACCOUNTS PDF / PRINT FIX

Problem:
The Accounts Report PDF was printing the on-screen scrollable table container.
A PDF cannot be scrolled, so columns/rows outside that box were effectively hidden.

Fix:
- Print/PDF uses A4 LANDSCAPE.
- All report scroll containers become normal expanded content when printing.
- Tables use full paper width.
- Long tables automatically continue onto additional PDF pages.
- Table headers repeat at the top of subsequent pages.
- Rows are kept together where possible.
- Text wraps inside cells instead of being clipped.
- Sidebar, top navigation, buttons and mobile controls are hidden from PDF.
- Summary cards remain printable above the registers.

No SQL / Supabase change.

UPLOAD ONLY:
1. app.js
2. index.html
3. service-worker.js

After deployment:
1. Ctrl + Shift + R.
2. Accounts → Reports.
3. Apply desired date/payment filters.
4. Click Print / PDF.
5. In Chrome print window choose "Save as PDF".
6. Layout should already be Landscape.

Version: 2.8.31
