What changed:
- Save confirmation is now a separate top-level overlay, not a normal page toast.
- It has the highest display layer, so modal windows, mobile navigation and page changes cannot hide it.
- SUCCESS = large GREEN confirmation with tick.
- FAILURE = large RED confirmation with exclamation mark.
- An OK button is provided.
- Confirmation remains visible for up to 8 seconds unless staff taps OK.
- Medication and Vital Signs saves use this confirmation.
- Existing global successful actions are also routed to the same confirmation.

No SQL / Supabase change.
