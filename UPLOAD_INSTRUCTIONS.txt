SAMARA CARE ERP v2.8.30 — MOG MONTHLY RESIDENT ID

NEW PERMANENT FORMAT:
MOG-YYYY-MM-####

Example:
MOG-2026-08-0001

Meaning:
MOG  = Mogappair centre
2026 = year of admission
08   = month of admission
0001 = running number within that centre/year/month

The sequence restarts each month:
MOG-2026-08-0001
MOG-2026-08-0002
...
MOG-2026-09-0001

Future centres can use the same structure:
ANN-2026-08-0001
POR-2026-08-0001

INSTALLATION ORDER
1. Recommended: export/backup the patients table.
2. Run 75_mog_monthly_resident_id.sql ONCE.
3. Replace only:
   - app.js
   - index.html
   - service-worker.js
4. Ctrl + Shift + R.

The SQL converts existing centre IDs to the monthly format using admission_date
(where available) and preserves the earlier ID in legacy_patient_id.

No other files are required.
