SAMARA CARE ERP v2.8.29 — REVISED FINAL PAYMENT MODES

THIS REPLACES THE EARLIER v2.8.29 PACKAGE.

Accepted payment modes ONLY:
1. Cash
2. UPI
3. RTGS
4. Card Payment

Removed:
- Cheque
- Bank Transfer
- old generic Card option

VOUCHER / REFERENCE RULES

Cash
- System-generated Cash Voucher.
- Format: CV-YYYY-000001
- Reference field is read-only.
- Transaction cannot be posted unless voucher is created.

Card Payment
- Same controlled procedure as Cash.
- System-generated Card Voucher.
- Format: CARDV-YYYY-000001
- Reference field is read-only.
- Transaction cannot be posted unless voucher is created.

UPI
- User must enter UPI Transaction Reference No.
- Save is blocked if reference is blank.

RTGS
- User must enter RTGS Transaction Reference No.
- Save is blocked if reference is blank.

The global GREEN success / RED failure confirmation is included across ERP and
Accounts Payment invokes it directly.

INSTALLATION
1. Run the revised 72_global_confirmation_cash_voucher.sql once.
   It is safe if the earlier v2.8.29 cash-only SQL was already run.
2. Replace:
   app.js
   index.html
   service-worker.js
3. Ctrl + Shift + R after deployment.

Version remains v2.8.29.
