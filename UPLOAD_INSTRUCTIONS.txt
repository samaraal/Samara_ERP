SAMARA CARE ERP v2.8.28 — PATIENT FILE STABILITY FIX

Why only some patients failed:
- The Patient File used composePatientAddress(selected) only when the stored address was blank.
- That helper exists inside the Admission form, not inside Patient File.
- Therefore patients with an existing address opened normally.
- Patients with missing/older address fields triggered:
  ReferenceError: composePatientAddress is not defined

So the behaviour looked related to the patient photograph, but the real deciding
factor was whether an address fallback was needed.

Fix:
- Patient File now uses the shared composePatientAddressGlobal helper through a
  local patientAddress() function.
- The v2.8.27 photo-size fix is preserved.

Upload only:
1. app.js
2. index.html
3. service-worker.js

No SQL / Supabase change is required.
