# Samara Care ERP V8.0 – Professional UI Refresh

This version changes only the presentation layer and visible version label. Application workflows, database operations, Supabase functions, authentication and existing records are unchanged.

## Improvements

- Larger fonts throughout the application
- Larger form labels and input text
- Bigger buttons and touch targets
- Taller, clearer table rows
- Larger dashboard numbers and headings
- Improved sidebar and submenu readability
- Better spacing in admissions, patients and employee forms
- Improved tablet and mobile readability
- New PWA cache version to prevent old CSS from loading

## Deployment

1. Replace the existing GitHub repository files with this package.
2. Commit the changes.
3. Wait for GitHub Pages deployment.
4. Press **Ctrl + Shift + R** once.
5. On a phone, close and reopen the browser or installed app.

No Supabase SQL or Edge Function update is required.
